Albert Correcteur Expérimental v0.8.0

Corrigez vos textes là où vous les écrivez.

Une extension pour Firefox, Thunderbird et Brave. Elle souligne les fautes dans les champs de saisie et traduit n'importe quelle sélection en quatre langues. Un clic remplace le mot.

Champ de saisie d'une page web

Je suis contant de vous revoir. Au jour d'aujourd'hui, cet exemple et prêt.

Orthographe

"contant" ne s'écrit pas ainsi quand on parle d'être satisfait.

content
Texte sélectionné, clic droit

Le rapport doit être remis avant vendredi.

  • Français
  • Anglais
  • Espagnol
  • Allemand

The report must be submitted before Friday.

Installer l'extension Voir le code source

Ce qu'elle fait

  • Elle souligne pendant que vous écrivez Dans les champs des pages web et dans la fenêtre de rédaction de Thunderbird.
  • Trois couleurs, trois types de faute Rouge pour l'orthographe, orange pour la grammaire, bleu pour le style. Un clic sur le mot ouvre la suggestion.
  • Elle traduit et elle reformule Par le clic droit sur une sélection. Quatre langues au choix : français, anglais, espagnol, allemand. La langue de départ est reconnue toute seule.

Il vous faut une clé Albert

L'extension ne corrige rien toute seule : elle envoie le texte à l'API Albert, le service d'intelligence artificielle de la DINUM, avec votre clé. Sans clé, elle ne fait rien.

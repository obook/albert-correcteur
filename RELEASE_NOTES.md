## Albert Correcteur v0.9.2

Après une correction, Ctrl+Z annule d'abord la frappe qui a suivi, puis la correction : la saisie n'est plus effacée. Les soulignements restent sur le bon mot pendant la frappe et les messages temporaires se ferment de nouveau seuls. Une reformulation ne remplace plus un texte modifié pendant son chargement.

Sous Brave, la fenêtre de traduction s'ouvre de nouveau.

Quand le menu contextuel ne peut pas agir sur une page (boutique d'extensions, pages internes du navigateur, PDF), une notification le signale. Firefox demandera d'accepter cette nouvelle permission lors de la mise à jour.

Avec un proxy local comme llm-proxy, la clé API est facultative : les limites du compte s'affichent sans elle.

### Téléchargements

- Firefox : extension signée par Mozilla (.xpi)
- Thunderbird : extension (.xpi)
- Brave / Chromium : archive (.zip)

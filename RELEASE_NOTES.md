## Albert Correcteur v0.9.3

La langue de correction se choisit : une langue par défaut dans les paramètres, et un sélecteur dans la popup de correction pour le champ en cours. Sur un texte anglais court, les suggestions étaient traduites en français.

Après une erreur de l'API, le badge reste lisible : plus de pulsation ni de superposition avec l'animation d'attente.

Sous Thunderbird, l'icône Albert apparaît dans la rédaction même quand l'API ne répond pas, le bouton Albert revient dans la barre de rédaction, et la popup de correction reste visible pour un mot en haut du message.

### Téléchargements

- Firefox : extension signée par Mozilla (.xpi)
- Thunderbird : extension (.xpi)
- Brave / Chromium : archive (.zip)

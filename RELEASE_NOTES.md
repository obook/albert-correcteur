## Albert Correcteur v0.9.0

La langue de traduction se choisit dans une liste déroulante, à la place des quatre boutons. Traduire un texte vers sa propre langue le rend maintenant tel quel au lieu de le réécrire en français.

Sur x.com, l'ascenseur du champ de rédaction recouvrait le badge et son animation d'attente. Le badge garde une marge avec le bord du champ et l'animation tient dans ses 16 px : le logo s'efface, deux points tournent à sa place.

Le lien de demande de clé API pointe vers le nouveau site Albert.

### Téléchargements

- Firefox : extension signée par Mozilla (.xpi)
- Thunderbird : extension (.xpi)
- Brave / Chromium : archive (.zip)

## Albert Correcteur v0.9.4

La correction est plus rapide. Avec le modèle large, les mots soulignés pouvaient mettre plus de 20 secondes à apparaître : le modèle raisonne maintenant moins longtemps. Avec les autres modèles, les instructions envoyées au modèle à chaque vérification sont trois fois plus courtes.

### Téléchargements

- Firefox : extension signée par Mozilla (.xpi)
- Thunderbird : extension (.xpi)
- Brave / Chromium : archive (.zip)
